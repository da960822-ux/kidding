# 지시보드·음성 전달 수정 검증 (2026-09-04)

사용자가 제시한 세 지시의 [최초 평가](../instruction-board-20260904/REPORT.md)를 바탕으로 화면, 전체 음성, 단위 표기를 병렬 수정했다. 로컬 코드 검증이며 운영 배포·게시·근로자 전송은 하지 않았다.

## 반영 내용

- 금지·주의사항을 담은 `context.notes` 전체를 근로자 첫 화면의 시작 버튼 위, 단계 화면, 농장주 대면 설명 화면에 항상 표시한다. 기존 안전 출처 검증은 유지한다.
- 기존 TTS 생성 경로를 유지하고 조립 텍스트에 위치, 객체 수량, 마감, 안전사항, 순서대로 모든 단계, 메모를 포함한다. AI 생성·BE 검증·브라우저 대체 음성은 같은 텍스트를 사용한다. 단계 음성에도 안전사항과 메모를 포함한다.
- 기존 저장 음성의 hash가 완전한 안내문과 다르면 동일한 전체 안내문의 기기 음성으로 전환한다. 이전 게시 버전이나 음성 파일을 덮어쓰지 않는다.
- 검증된 사전 번역을 우선하고, `망`의 fallback 표기는 베트남어 `bao`, 네팔어 `बोरा`로 고정한다. 문장 번역에도 동일 단위와 부정·수량 보존 지침을 적용한다.

## 검증 결과

| 검증 | 결과 |
| --- | --- |
| AI 단위·번역 문맥·전체 안내문 회귀 | 28/28 통과 |
| BE 단위 테스트 | 107/107 통과 |
| 브라우저 notes·저장 음성·기기 음성 회귀 | 9/9 통과 |
| TypeScript 및 프로덕션 빌드 | 통과 |
| 실제 번역·TTS 패키지 | 예시 ①·③ × vi/ne, 총 4개 생성·텍스트/hash 검증 통과 |
| 실제 MP3 브라우저 재생 | 예시 ③ × vi/ne × 390/1100px, 총 4개 통과 |

실제 패키지 생성은 최초 평가에서 저장한 구조화 결과를 사용했다. 현재 가이드·영상 데이터를 읽어 번역과 TTS를 호출했으며 DB 쓰기는 하지 않았다. 브라우저에는 해당 패키지를 읽기 응답으로 제공했다. 첫 화면의 메모가 시작 버튼보다 앞에 있고, 단계에서도 표시되며, 화면 이동 시 재생이 중지됨을 확인했다. 페이지 오류와 가로 넘침은 없었다. 네팔어 데스크톱 단계 스크린샷은 화면 이동 스크롤이 끝난 뒤 다시 캡처했다.

예시 ③은 `20 bao` / `20 बोरा`, 마감, 수확→선별→운반, 상하거나 무른 양파 분리, 상자·창고, 던지지 말라는 메모를 포함한다. 베트남어 실제 음성 길이는 22.656초, 네팔어는 22.704초다.

## 범위와 남은 한계

예시 ②는 기존 평가에서 두 금지사항이 메모에 보존됐지만 실행 단계가 없어 게시 차단됐다. 이번 수정은 금지문만으로 작업 단계를 추측해 만들거나 이 차단을 해제하지 않는다. 실행 가능한 작업에 포함된 두 금지문이 화면·대체 음성에 보존되는 경우는 브라우저 회귀로 확인했다.

이번 검증은 텍스트에서 생성한 안내문과 TTS 전달에 대한 것이다. 새 STT 입력이나 사람 원어민의 의미·발음 검수는 수행하지 않았다. 단위 번역 실험 중 네팔어에 한국어 조사 `씩`이 남은 실패도 원시 결과에 유지했다. 지침 보완 후 마지막 해당 문장은 통과했지만 모든 표현의 번역 품질을 보장하는 결과는 아니다. 브라우저 기기 음성의 언어 지원은 실행 기기에 따른다.
