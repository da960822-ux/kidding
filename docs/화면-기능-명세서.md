# 밭머리 P0 화면·기능 명세서

이 문서는 양파·딸기 작업지시 P0의 현재 웹 화면만 정의한다. 제품 범위와 충돌하면 `AGENTS.md`, `CONTEXT.md`, `docs/PRODUCT_SPEC.md` 순서로 따른다.

## 공통 원칙

- 로그인 화면은 없다.
- 랜딩 언어는 한국어·베트남어·네팔어이며 역할 선택과 근로자 진입 화면까지 유지한다.
- 근로자 작업 내용은 WorkerLink에 지정된 베트남어 또는 네팔어만 표시한다.
- 국적은 안내 언어가 아니다. 선택 가능한 국적은 `VN|PH|LA|KH|TH|NP|MM|MN`이다.
- 주요 버튼은 모바일에서 최소 44×44px를 유지한다.
- 웹앱 글자는 랜딩의 같은 위계보다 3pt 크게 표시한다.
- 작업 영상은 `APPROVED`, `LOW`, `AI_GENERATED_PREGENERATED` 조건을 모두 만족할 때만 표시한다. 그 외에는 텍스트와 TTS를 사용한다.

## 화면 목록

### C-01 랜딩

- 서비스 범위와 사용 방법을 소개한다.
- 언어를 선택한다.
- `시작하기`로 역할 선택 화면에 이동한다.

### C-02 역할 선택

- 제목: `어떤 역할이신가요?`
- 농장주와 근로자 카드만 표시한다.
- 농장주 선택 시 자동 demo owner session을 발급하고 농장주 홈으로 이동한다.
- 근로자 선택 시 오늘 작업팀 참여 화면으로 이동한다.

### O-01 농장주 홈

- 새 작업 지시 시작
- 오늘 작업팀 QR 생성 화면 이동
- 최신 진행 작업 열기
- owner session이 만료되면 프런트가 한 번 자동 재발급하고 원래 요청을 재시도한다.

### O-02 오늘 작업팀

- 오늘 active team이 없으면 `오늘 작업팀 열기`를 표시한다.
- API의 `join_url`을 `qrcode.react`로 렌더링한다.
- 참여 링크 복사와 만료시간을 표시한다.
- 참여 근로자를 이름·별명, 국적, 안내 언어 순으로 표시한다.
- 목록은 4초마다 다시 조회한다.

### O-03 음성 작업지시

- 농장주 음성을 최대 60초·10MiB로 녹음한다.
- 녹음 종료, 재녹음, 제출, 권한 오류를 제공한다.
- 목 API에서는 양파 또는 딸기 데모를 선택할 수 있다.

### O-04 AI 해석 확인

- 한국어 요약, 작업 단계, 장소, 수량, 마감, 안전, 메모를 확인한다.
- ambiguity는 한 번에 하나만 크게 표시한다.
- `SAFETY`, blocking ambiguity, HIGH·UNKNOWN 위험, 실행 단계 없음은 전달을 차단한다.
- 허용되는 non-blocking ambiguity만 농장주가 이유를 직접 선택해 전달할 수 있다.
- 보완은 음성으로만 받는다.

### O-05 전달 방법 선택

- `현장에서 같이 보기`와 `링크로 보내기` 중 하나를 선택한다.
- 안내 언어는 베트남어 또는 네팔어다.
- 같이 보기는 owner briefing으로 이동한다.
- 링크 보내기는 24시간 WorkerLink를 생성하고 복사·열기 기능을 제공한다.

### O-06 현장에서 같이 보기

- 선택 언어의 최신 PUBLISHED 버전을 5초마다 조회한다.
- 단계별 영상, 텍스트, TTS를 제공한다.
- 새 버전이 오면 재생을 멈추고 첫 단계로 이동한다.
- 이 화면에는 `이해했어요`를 표시하지 않는다.

### O-07 진행 중 작업

- 최신 작업 단계와 버전, 장소, 수량, 마감, 안전을 표시한다.
- 전달 화면과 수량 변경 화면으로 이동한다.

### O-08 수량 변경

- 변경할 수량을 음성으로 입력한다.
- AI 해석 결과가 READY일 때 농장주가 직접 확인해야 새 버전을 만든다.
- `409 VERSION_CONFLICT`이면 최신 작업을 다시 불러오고 변경 입력을 초기화한다.

### W-01 오늘 작업팀 참여

1. 국적을 선택한다.
2. 농장주의 QR을 스캔하거나 참여 링크를 입력한다.
3. 이름 또는 별명을 입력한다.
4. 최종 참여 요청이 성공한 뒤 QR 참여 URL을 주소에 반영한다.

QR 인식만으로 이동하거나 팀원을 생성하지 않는다. 카메라를 쓸 수 없으면 링크 직접 입력을 유지한다. 고정 테스트 링크는 목 API에서만 표시한다.

### W-02 개인 작업지시

- 익명 WorkerLink의 최신 PUBLISHED 작업만 표시한다.
- 장소, 수량, 마감, 안전, 메모, 단계는 선택 언어만 사용한다.
- 5초 polling과 화면 복귀 재조회로 최신 버전을 확인한다.
- 만료·접근 불가 응답이면 기존 작업을 즉시 지운다.

### W-03 개인 작업 단계

- 단계별 영상 또는 텍스트·TTS fallback을 제공한다.
- 이전·다음 단계와 자막을 제공한다.
- 마지막 단계의 `이해했어요`는 개인 WorkerLink 화면에서만 표시한다.
- `이해했어요`는 P0에서 서버 완료 기록을 만들지 않고 개인 화면을 최신 작업 목록으로 되돌리는 동작이다.

### W-04 개인 링크 오류

- 만료와 접근 불가를 선택 언어로 안내한다.
- 만료가 아니면 다시 시도 버튼을 제공한다.
- 한국어 작업 내용을 fallback으로 노출하지 않는다.

## 화면 이동

```text
랜딩
└─ 역할 선택
   ├─ 농장주 홈
   │  ├─ 오늘 작업팀 QR
   │  ├─ 음성 작업지시 → AI 확인 → 전달 방법
   │  │                         ├─ 같이 보기
   │  │                         └─ 개인 WorkerLink 생성
   │  └─ 진행 중 작업 → 수량 변경
   └─ 근로자
      ├─ 국적 → QR/링크 → 이름·별명 → 오늘 작업팀 참여
      └─ 개인 WorkerLink → 최신 작업 → 단계별 보기
```

## P0 제외

- 로그인·회원가입·PIN
- 별도 작업자 언어선택 화면
- 사진 첨부
- 일반 번역
- 질문·답변
- 알림 목록과 설정
- 근로자 확인·완료 상태의 서버 저장
- 양파·딸기 이외 작물과 베트남어·네팔어 이외 작업 번역
- TodayWorkTeam 팀원과 WorkSession의 개인별 배정
