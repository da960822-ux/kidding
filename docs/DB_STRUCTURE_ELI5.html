🧅🍓📒

밭머리 DB는
농장 작업 노트다

말로 한 양파·딸기 작업지시를 적어 두고, 확인한 최신 내용을 외국인 근로자에게 보여주는 작은 노트다.

전체 흐름

🎙️

농장주가 말함

“양파 20망 손질해줘.” 또는 “딸기 20상자 포장해줘.”

→
✏️

AI가 초안 작성

아직 연필로 쓴 메모다. 농장주 확인 전에는 확정이 아니다.

→
✅

농장주가 확인

확인한 내용만 최신 작업으로 보관한다.

DB 안의 7개 서랍

✏️
초안 서랍

work_drafts

AI가 해석한 작업 메모.

농장주가 확인하기 전까지만 존재한다.

🗂️
작업 묶음 서랍

work_sessions

오늘 한 장소에서 할 양파 또는 딸기 작업 한 묶음.

예: “밭 A의 오늘 작업”.

📸
사진 서랍

work_versions

확인된 작업의 사진 같은 고정본.

처음은 v1, 수량 변경은 v2. 옛 버전은 SUPERSEDED.

🔗
초대장 서랍

worker_links

근로자 개인정보가 아닌 익명 링크.

언어 하나만 선택. 24시간 유효. 언제나 최신 PUBLISHED를 보여준다.

📖
표현 원문 서랍

guide_phrases

검수할 정부 가이드의 한국어 표현.

작업 표현과 안전 표현을 구분한다.

🌏
번역 서랍

guide_translations

원문 표현의 베트남어(vi)·네팔어(ne) 번역.

사람이 확인해야 공식 번역이라고 부른다.

🎬
영상 서랍

visual_assets

양파·딸기 작업 영상의 주소와 검수 기록.

AI 사전 생성 + 사람 승인 + LOW 위험만 게시한다.

수량이 바뀌면?

20망 → 15망

기존 사진을 지우고 고치지 않는다.

새 사진 v2를 만든다. v1은 옛 사진으로 남는다.

그래서 링크를 가진 사람도 최신 수량을 본다.

안전 규칙

모르면 빈칸으로 둔다.

AI가 위험을 모르면 게시하지 않는다.

위험한 영상, 검수 안 된 안전 번역도 게시하지 않는다.

이 DB에 없는 것

이번 P0는 사람을 등록하는 서비스가 아니다.

workers 전화번호 SMS 근로자 로그인 채팅

농장주와 같이 보는 CO_PRESENT 또는 익명 24시간 링크만 사용한다.

기준: 밭머리 P0. 양파·딸기만, vi/ne만, 수량 변경만.
