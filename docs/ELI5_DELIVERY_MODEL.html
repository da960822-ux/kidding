밭머리는 어떤 서비스일까?

아주 쉽게 말하면, 농장주가 선생님이고 근로자가 학생인 작업 전달 도구예요.

농장주
“양파 20망 해줘”
→
오늘 작업 공책
WorkSession
→
근로자별 초대장
WorkerLink

추천하는 모습

농장주가 오늘 작업을 하나 만들어요.

근로자 A, B, C에게 각각 비밀 초대장(URL)을 보내요.

세 사람은 같은 작업을 보지만, 자기 언어로 봐요.

URL은 오픈카톡방일까?

아니에요. URL은 “작업표를 보는 열쇠”에 가까워요.

채팅 없음 검색 없음 답장 없음 24시간 후 만료

누구나 들어오는 방이 아니라, 초대받은 사람이 오늘 작업을 보는 화면입니다.

작업표를 사람마다 복사할까?

같은 일을 하면 복사하지 않아요.

칠판에 “오늘 양파 20망”이라고 한 번 쓰고, 모두가 그 칠판을 봅니다.

사람마다 다른 양·작업이 필요할 때만 나중에 개인 작업표를 추가해요.

개인정보 DB가 필요할까?

처음에는 이름표만 있으면 돼요.

  • 공개용 가명: 근로자 A
  • 언어: 베트남어 또는 네팔어
  • 활성 여부

전화번호, 주민번호, 실명, SMS는 처음부터 모으지 않습니다.

공공기관은 언제 넣을까?

지금은 학교를 직접 운영하는 단계가 아니라, 선생님이 학생에게 공책을 나눠주는 단계예요.

나중에 공공기관이 농장과 근로자를 연결해 주면, 그때 기관용 계정·권한·개인정보 관리를 붙이면 됩니다.

한 줄 결론

지금은 “농장주 1명 → 오늘 작업 1개 → 근로자별 URL”로 만들면 됩니다.

현재 DB의 WorkSession, WorkVersion, Worker, WorkerLink가 바로 이 구조예요.
