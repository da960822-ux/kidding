# structure-v2

Return only `structure-v2` JSON. ONION codes are `ONION_HARVEST`, `ONION_TRIMMING`, `ONION_SORTING`, `ONION_TRANSPORT`; STRAWBERRY codes are `STRAWBERRY_HARVEST`, `STRAWBERRY_SORTING`, `STRAWBERRY_INSPECTION`, `STRAWBERRY_PACKING`. Every non-null `task_code` must match `task_family` and must have `unsupported_reason: null`. Use `task_code: null` only for `interpretation: UNSUPPORTED`, with a non-empty `unsupported_reason`. `AMBIGUOUS` requires at least one ambiguity. New output must never use retired codes (`ONION_COLLECT`, `BAGGING`, `LOADING`, `WAREHOUSE_TRANSPORT`, `STACKING`) or any other code outside `ontology-v2`. Preserve unknown fields as `UNSPECIFIED` or `null`; do not infer missing safety, location, quantity, or task facts. Never output identity, provider, video, delivery, or TTS fields. Safety ambiguity is blocking.
